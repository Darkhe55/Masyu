# 珍珠（Masyu）· 逻辑谜题

在格子之间画一条闭合回路，让回路经过所有圆圈，并按圆圈规则直行 / 转弯。
纯前端实现（Vite + TypeScript + 原生 SVG，无框架），内置题库、实时校验、错误高亮、
回溯求解、提示一格、逻辑解题回放与自定义题板。

- 开发端口：**5215**（`npm run dev` → http://127.0.0.1:5215/）
- 存储：开发服务器下题库/进度写在项目内 `data/`（`library.json` / `progress.json` / `last-puzzle.json`），静态预览时自动降级到浏览器 localStorage

## 规则

1. 在**相邻两个格子之间**画线，所有线连成**一条**不交叉、不分叉的闭合回路；
2. 回路必须经过**每一个圆圈**；
3. **白圈**：回路在白圈处必须**直行**，且相邻的两格中**至少一侧要转弯**；
4. **黑圈**：回路在黑圈处必须**转弯**，且相邻的两格**都要直行**；
5. 回路可以经过没有圆圈的格子，也可以留空不经过；
6. 内置题都保证**唯一解**；题目都可以用「逻辑解题」直接推完。

## 操作

### 鼠标

- <kbd>左键</kbd> 点击两个相邻格子之间的位置：画线；点已画的线取消；
- <kbd>右键</kbd>：标叉（排除）/ 取消叉；右键点在线上会把线改成叉；
- <kbd>按住左键拖拽</kbd>：沿途连续画线；
- <kbd>中键/拖拽空白</kbd>：平移画布；<kbd>滚轮</kbd>：缩放；画布上方有 `− / + / 复位` 按钮。

### 键盘

- <kbd>方向键</kbd>：移动虚线光标（在格子之间的候选线上移动）；
- <kbd>空格</kbd> / <kbd>回车</kbd>：在当前光标处画线 / 取消线；
- <kbd>X</kbd> / <kbd>Backspace</kbd> / <kbd>Delete</kbd>：在当前光标处标叉 / 取消叉；
- <kbd>Z</kbd> 撤销 · <kbd>Shift+Z</kbd> / <kbd>Y</kbd> 重做；
- <kbd>C</kbd> 检查 · <kbd>L</kbd> 逻辑解题 / 停止回放 · <kbd>P</kbd> 暂停/继续回放；
- <kbd>R</kbd> 随机抽题 · <kbd>M</kbd> 音效开关 · <kbd>Esc</kbd> 清空盘面；
- <kbd>+</kbd> / <kbd>−</kbd> / <kbd>0</kbd> 放大 / 缩小 / 复位。

### 工具栏

`检查` 立即校验并给出中文说明；`撤销 / 重做`；`提示一格`（优先补一条缺的线，也会擦掉画错的线）；
`逻辑解题`（规则推理逐帧回放，可暂停/停止）；`显示解`；`清空`。

错误会直接标在棋盘上：圆圈画错变红圈，断头/分叉标红点，多出来的环画成红线。

## 自定义题板

点左侧「自定义」：

- 宽高范围 **2×2 ~ 20×20**；
- 点击格子循环：空 → 白圈 → 黑圈（键盘 `1` 白圈、`2` 黑圈、`0`/`Backspace` 清空，方向键移动，`Enter`/`Tab` 下一格）；
- `载入题板`：立刻载入并加入题库；
- `保存到题库`：保存（保存/求解时会用回溯求解器校验**唯一解**，并在提示里说明结果）；
- `求解` / `逻辑解题`：同工具栏；
- 题库里的自定义题可以 `编辑` 回填题面（保存覆盖原题），`×` 需要**点两次确认**才会删除。

## 启动 / 构建 / 测试

```bash
npm install        # 安装依赖
npm run dev        # 开发服务器：http://127.0.0.1:5215/
npm run build      # tsc 类型检查 + vite 生产构建（输出 dist/）
npm run check      # 题库审计：编码 / 参考解 / 规则推满 / 唯一解
npm run gen        # 重新生成内置题库（src/game/puzzles-data.ts）
npm run ui-check   # Playwright 冒烟测试（需要先 npm run dev）
```

`npm run check` 会逐题检查：

1. 题面编码合法（`board` 长度 = 宽×高，`solution` 长度 = 边数）；
2. 参考解合法（回路单环、无断头分叉、所有圆圈规则满足）；
3. 从空盘出发规则传播（含反证规则）能推满，且结果等于参考解 —— 即可逻辑推完；
4. 回溯求解器数解 **恰好 1 个**。

审计脚本直接 `import` `src/game/*.ts`（Node 24 原生去类型），和浏览器跑的是同一份规则/求解代码。

## 实现要点

- **状态**：每条候选边 0 未定 / 1 连线 / 2 叉；边索引与 `src/core/board.ts` 一致
  （水平边先行，`y*(w-1)+x`；竖直边在后，`h*(w-1)+y*w+x`）。
- **校验**：只看已连的线，检查每格度数、圆圈直行/转弯与邻格直行/转弯、单环、断头、分叉，并给出中文状态说明。
- **传播**：把每格可能的连法（空 / 2 直行 / 4 转弯）做成掩码，做局部约束 + 邻格约束 + 全局回路约束到不动点；
  再加「反证」规则（假设一条边连/不连，若规则系统立刻矛盾则取反），内置题靠它完全推满。
- **求解器**：传播 + MRV 回溯，节点/时间双预算；`countSolutions` 用于自定义题唯一解校验。
- **生成器**：backbite 随机游走生成哈密顿回路（奇数格盘面留 1 格），在回路的合法位置摆圆圈，
  用传播 + 求解器筛出「唯一解且可逻辑推完」的题，再贪心删线索。

## 已知限制

- 自定义题唯一解校验有时间预算（约 1.2s / 16 万节点），超大或圆圈极少的盘面可能返回「校验超时」，
  此时仍可保存，但无法确认唯一解；
- 20×20 级别的自定义盘面「逻辑解题 / 显示解」可能触及求解预算，状态栏会明确提示超时；
- 键盘光标按「候选边中点」在上下左右半平面内找最近的边移动，属于便捷操作，不是严格网格步进；
- 音效为 Web Audio 合成音（无外部音频文件）。

## 图片导入

`npm run import-image -- <图片路径>` 可以自动识别珍珠（Masyu）题图里的圆圈阵列：按填充率区分白圈/黑圈，用最小二乘拟合格点后生成棋盘编码。

```bash
npm run import-image -- 题图.png --dry                 # 只识别与预览
npm run import-image -- 题图.png --name "我的珍珠" --append   # 追加到题库
npm run import-image -- 题图.png --append --verify      # 额外做唯一解检查（大图会超时警告）
```

| 参数 | 说明 |
|------|------|
| `--size N` / `--width W --height H` | 覆盖棋盘尺寸（圆圈不够贴边时用） |
| `--map 0=w,1=b` | 交换两类圆圈的映射（0=空心环、1=实心盘） |
| `--name` / `--id` | 题库名字 / id |
| `--append` | 写入 `src/game/imported-puzzles.ts` |
| `--verify` / `--dry` | 唯一解检查 / 只识别 |

说明：导入题写到 `src/game/imported-puzzles.ts`（`npm run gen` 不会覆盖）；最大边长上限已放宽到 40 以容纳每月大题。
